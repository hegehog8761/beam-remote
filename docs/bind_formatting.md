# Formatting key binds correctly
## The layout of key binds
- All letters should be lower case
- To add a modifier, just type the modifier then a space, then the key. This means that it should follow the general format "{modifier} {key}", e.g. "ctrl a"
- To add a second modifier, add a hiphen (-) between the two modifiers. It should follow the format "{modifier}-{modifier} {key}", e.g. "ctrl-shift a"
## Accepted binding
### Accepted modifiers
|Modifier|Notes|
|---|---|
|`lshift`|The left shift key, can be used to give more binds than just `shift`|
|`lcontrol`|The left control key (ctrl)|
|`rshift`|The right shift key|
|`rcontrol`|The right control key (ctrl)|
|`alt`|
|`ctrl`|Either control key - can make it easier to use the binds on a keyboard|
|`shift`| Either shift key|
